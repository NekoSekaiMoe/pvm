# Scripts (`scripts/`)

This directory contains utility shell scripts used throughout the PVM development lifecycle.

## Common Uses
- **Environment Setup**: Scripts to configure host prerequisites (e.g., loading `tun` modules, setting up NAT).
- **Build Scripts**: Automation for compiling Go binaries, eBPF programs, or building the WebUI frontend.
- **CI/CD**: Scripts executed by GitHub Actions or other CI pipelines.
